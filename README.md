# About this Project
Hello my name is Joseph Sierra and I'm making a home lab with VMs to gain hands-on experience using the SIEM tool from Wazuh to find failed login attempts or changes to a file. I will be running 2 VMs with Virtualbox, one will be using Ubuntu Server as the OS and have Wazuh installed (wazuh-server) while the other will have Windows while having the Wazuh agent installed (windows-endpoint). The goal is to have the wazuh-server monitor the windows-endpoint for failed login attempts and/or changes made to files through the Wazuh agent that is installed in the windows-endpoint. I will document the process from installation to troubleshooting and finally to the results as i work on this lab.
